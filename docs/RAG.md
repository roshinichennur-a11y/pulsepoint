# Retrieval integration boundary

No live RAG is implemented. The frontend currently uses three curated NCI URLs, checked during development on 2026-09-25. They are living resources, so no invented publication or update date is displayed. The snippets are original descriptions of resource scope, not extracted clinical passages.

When the evidence service is ready, return source provenance through the agreed Source fields. Any unavailable/unverified result must remain visibly labeled. Future clinical synthesis needs evidence-to-claim citation mapping, clinical review, freshness handling, and disagreement/uncertainty presentation. Do not substitute generated citations for missing retrieval results.
