# Prototype boundaries

Synthetic cases only. No diagnoses, prescribing, patient-specific treatment decisions, or claims of clinical validity. Experts and expert responses are explicitly fictional in demo mode. Synthesis is a template, not an LLM answer, and is labeled as such. Match scores are demo routing scores, never correctness probabilities.

The app does not de-identify inputs. Do not enter real patient information. The graph's synthetic dataset is independent of questions; it is not a claim that anonymization exists. Demo input persists in this browser tab's session storage and can be cleared in About this demo. Voice input may be processed by the browser vendor's speech service. No voice audio is stored by PULSEPOINT.

The API integration preview has no authentication or authorization. Keep it local and synthetic until the team adds appropriate access control, privacy protections, expert verification, source validation, and clinical governance. Never store secrets in public frontend environment variables.
